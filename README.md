# 🚀 Dashboard Backend

REST API for implementing a dashboard.

## 🛠️ Technology stack

Java 21, Maven, Spring Boot, JPA, PostgreSQL, Liquibase.

## 💻 Database configuration

The application uses PostgreSQL as a persistent storage. Options to get it up:

1. Use a remote existing PostgreSQL. It is needed to specify the path in configs.
2. Start local postgres in docker `docker compose -f compose.yaml up -d`
